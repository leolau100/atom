# 多公众号发布说明（publish.py）

脚本路径：`/Users/liulei/Product/01_PubWechatFile/publish.py`
渲染产物：`/Users/liulei/Product/06_NiceWeChatFile/wf.html`（由 `render_article.py` 生成，必须串行渲染）

## 两个登录态（持久 Profile）

每个微信号一个独立目录，登录态互不干扰：

| 目录 | 对应公众号 | 状态 |
|------|-----------|------|
| `.publish_profile`   | 号 A（DoublePoint / 未来技术观察） | 已登录 |
| `.publish_profile_b` | 号 B（aric / 时界之外）            | 已登录 |
| `.publish_profile_c` | 号 C（三一 / 燕麦粥lab）           | 目录已建，**首次需扫码** |

> 首次用 `.publish_profile_b` 跑脚本时，弹出的 Chrome 窗口请用**微信号 2** 扫码登录；登录态会存进该目录，之后基本免扫码（除非微信登录态过期）。

## 发布命令模板

```bash
# 号 A（沿用现有登录态）
python3 publish.py \
  --profile /Users/liulei/Product/01_PubWechatFile/.publish_profile \
  --author "作者A" --card-name "未来技术观察" \
  --html wf.html --title "标题" --collection "合集名"

# 号 B（用新建的目录，首次扫码）
python3 publish.py \
  --profile /Users/liulei/Product/01_PubWechatFile/.publish_profile_b \
  --author "aric" --card-name "时界之外" \
  --html wf.html --title "标题" --collection "合集名"

# 号 C（燕麦粥lab，首次扫码；主题 qbitai，footer 用 footer-oatmeallab.html）
python3 publish.py \
  --profile /Users/liulei/Product/01_PubWechatFile/.publish_profile_c \
  --author "三一" --card-name "燕麦粥lab" \
  --html wf.html --title "标题" --collection "合集名"
```

> 号 C 渲染命令（在 `06_NiceWeChatFile` 目录执行）：
> ```bash
> python3 render_article.py \
>   --md /abs/path/to/文章.md --theme qbitai --footer footer-oatmeallab.html
> ```

## 参数含义

| 参数 | 默认 | 说明 |
|------|------|------|
| `--profile`   | `.publish_profile` | 持久登录态目录，每个微信号一个 |
| `--account`   | 空 | 登录后自动切到该公众号（名称/原始ID）；不同微信号场景一般留空 |
| `--author`    | `DoublePoint` | 作者名 |
| `--card-name` | `未来技术观察` | 文末账号名片；传空字符串 `""` 则不插入名片 |
| `--collection`| `开源物联网平台` | 微信合集名；留空则不勾选 |
| `--title`     | — | 文章标题 |
| `--html`      | `wf.html` | 渲染产物路径 |
| `--source`    | `个人观点，仅供参考` | 创作来源声明 |

## 注意事项

1. **同一 `--profile` 目录不能同时跑两个进程**（持久 profile 只能被一个 Chrome 占用）。两个号用不同目录即可并行。
2. 两个号的 `--author` / `--card-name` / `--collection` 通常不同，记得各自传参。
3. 脚本只**存草稿**，最后仍需在微信后台手动「发表」。
4. 扫码登录窗口可能被其他 Chrome 遮挡 → 看 `publish.py` 已做二维码每 10 秒刷新 + 窗口强制置顶；二维码文件在 `/tmp/wechat_qr.png`，日志在 `/tmp/publish.log`。
