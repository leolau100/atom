约 2 万 star 的 text-to-cad，让 AI 智能体直接写 Python 建模脚本，在本地长出能上机床的三维模型。

它不输出渲染图，输出的是可拆解、可改参数、可出工程图的真几何。

榜单第六位，方向是「文本生成 CAD」：一句自然语言需求，落到可加工、可打印、可装配的模型。

建模走本地工作流：插件加技能，数据不传云端，模型在你的机器上生成、在你的机器上预览。

脚本随时能打开改参数、重新生成——可编辑，是它和"AI 画图"的分界线。

官方预览图里的彩色行星齿轮组，是从可编辑 CAD 几何渲染出来的，不是一张死图。

它能做什么

零件与装配体。

底层用 build123d，一个基于 OpenCASCADE 几何内核的 Python 库，参数化描述实体模型。

导出格式覆盖 STEP、STL、3MF、GLB，另有 DXF 轮廓与展开图，供激光切割和水刀下料。

装配体可定义关节和动画，表达机构运动关系，并在 CAD 浏览器里实时查看。

同一份几何能切换着色与线框：着色看外形，线框看拓扑和约束关系。

X 光模式透视内部结构；爆炸视图把零件沿装配方向拆开，检查配合、间隙和螺栓走向。

工程图与标注。

从几何投影出带尺寸的 PDF 工程图：视图、隐藏线、中心标记、孔位标注、标题栏齐全。

带标注的图由它自动生成，不靠人手描。

可制造性检查。

逐项对照工艺规则，判断零件能否机加工、切割折弯、注塑或 3D 打印，并指出做不了的地方该改哪里。

电路板设计。

处理 KiCad 原理图与板子，完成布局布线，用 ERC 和 DRC 做电气与制造规则检查，下单前复审后导出制造文件。

制造服务对接。

上传前按第三方规范检查 DXF 和 STEP 文件；3D 打印能切片并发送到对应打印软件。

机器人与仿真。

生成机器人本体与世界描述文件：ROS 用 URDF，MoveIt 用 SRDF，Gazebo 用 SDF，供仿真与运动规划。

技术内核

build123d 负责用 Python 参数化、可编程地描述实体，OpenCASCADE 是底层几何内核。

智能体生成的不是像素，是一段可执行建模代码；代码跑通，模型就长在 CAD 内核里。

STEP 是机械行业交换三维模型的事实标准，STL 和 3MF 面向增材制造。

GLB 适合可视化与网页展示，DXF 连着二维切割设备。

适配与上手

它做成"插件加技能"，不绑定某一个智能体：只要支持插件或技能，就能接上这套 CAD 能力。

官方适配覆盖代码类智能体、各家通用助手和开源智能体框架，让"会写代码、能跑命令"的智能体获得建模、检查、出图、对接制造的全套本领。

macOS 和 Linux 上一条命令装进每个智能体应用，自动配置插件（含技能与 CAD 的 MCP 服务）、注册命令行、切到新版本。

Windows 用对应的 PowerShell 命令；装好后向智能体要零件或装配体，它写 Python 脚本、运行构建、在 CAD 浏览器里展示。

再跑一遍安装命令即可整体更新。

项目默认发送使用统计和崩溃报告，以随机 ID 标记，不含文件、路径和提示词；官方公开了发送内容与关闭方法。

AI 只当建模助手，不包办一步到位。

从自然语言到可制造几何，它把这条链路做成开放、本地、可编辑、可审计的工作流。

物联网、工控、数字孪生要大量定制结构件、要把虚拟模型落到真实硬件，正需要这套能力。
