大家好，我是aric。

你家的路由器、门口的摄像头、公司的网络打印机——这些「嵌入式设备」几乎成了现代人生活中最容易被忽略的安全盲区。它们的固件更新慢、出厂默认口令千年不变、甚至出厂就带着已知漏洞。对做安全研究的人来说，逐个手动去验证一台设备有没有被攻破的风险，是件极其枯燥又重复的事。于是就有人把这套流程做成了工具：把「扫描漏洞、验证利用、爆破口令」打包成模块，跑一条命令就能自动把一台设备从头到尾过一遍。

今天要聊的这款开源框架，就是为嵌入式设备而生的漏洞利用框架，目前在开源社区已经攒下超过一万三千颗星，被不少人称作「物联网版的 Metasploit」。它用纯 Python 写成，整个设计思路就是：把对路由器、摄像头这类设备的渗透测试，变成一套可以复用的模块化流程。

它最核心的价值，是「模块化」。框架把安全测试拆成了几类职责清晰的模块：第一类是 exploits，也就是真正去利用某个已知漏洞的模块；第二类是 scanners，负责在动手之前先探测目标到底有没有中招的漏洞；第三类是 creds，专门用来对网络服务的口令做爆破测试；第四类是 payloads，负责为不同的处理器架构和注入点生成攻击载荷；还有 generic 类，做那些不依赖特定漏洞的通用攻击。这样的分层，让研究者可以像搭积木一样组合测试流程，而不是每次都从零写脚本。

它的使用方式也和老牌的 Metasploit 一脉相承：启动之后进入一个交互式控制台，你可以 use 某个模块、set 目标的 IP 和端口、然后 run 或者 check。check 会先帮你确认目标是否存在该漏洞，run 才会真正执行利用。这种「先验证、后利用」的工作流，对避免误伤和反复试错非常关键。[图里展示的]正是框架在自动扫描一台目标设备时的终端画面：一行行以 [-] 开头的是某条漏洞的检查结果，[-] 后面跟着目标地址、端口、协议，以及对应的模块路径——你能看到 netgear、cisco、huawei、3com、thomson 等一众厂商的目录，框架会逐个去试探这台设备是否命中已知漏洞。少数以 [*] 开头的行，表示那条漏洞暂时无法确认，需要人工补验。

为什么要把火力集中在「嵌入式设备」上？因为这一类设备的处境太特殊了。和服务器、PC 不同，路由器、摄像头、智能家居网关的固件往往由第三方外包团队赶工出来，安全审计普遍薄弱；更重要的是，它们大多直接暴露在局域网甚至公网上，却常年不更新。默认口令（比如 admin/admin）在大量设备上仍然有效，这给自动化测试框架留下了巨大的用武之地。这个框架内置了几百家厂商的漏洞模块，相当于把过去十年里公开的嵌入式设备漏洞，整理成了一份可以一键调用的字典。

rsf ＞ use exploits/routers/netgear/dgn2200_dnslookup_cgi_rce rsf (netgear_dgn2200_dnslookup_cgi_rce) ＞ set target 192.168.1.1 [+] target =＞ 192.168.1.1 rsf (netgear_dgn2200_dnslookup_cgi_rce) ＞ check [+] Target is vulnerable rsf (netgear_dgn2200_dnslookup_cgi_rce) ＞ run

上面这段，就是它控制台里最典型的操作节奏：先用 use 选中一个针对某厂商设备的远程代码执行模块，set 目标地址，check 确认漏洞存在，最后 run 执行。整个过程不需要你懂漏洞原理，照着模块路径填参数即可——当然，真正的安全研究远不止「跑一条命令」这么简单，但框架确实把门槛降到了很低。

和 Metasploit 的关系也值得说清楚：两者不是替代，而是互补。Metasploit 的覆盖面更偏通用主机和操作系统，而这个框架把重心完全压在物联网和嵌入式设备这一亩三分地上，厂商模块库是它的护城河。做物联网安全的人，往往两个都得备着。

也正因为它把已知漏洞整理得这么齐，它在防御侧同样有价值。设备厂商在固件发布前，完全可以用它把自己的产品跑一遍，看会不会被一打就穿；企业蓝队也能拿它定期扫描内网里那些被人遗忘的摄像头和路由器，把暴露在公网上的脆弱设备先揪出来。说白了，攻击者用的武器，防守方同样能用来自检——把漏洞在出厂前堵死，总好过上线后被别人捅穿。这几年各国陆续出台物联网设备的安全准入标准，强制设备改掉默认口令、建立漏洞响应机制，这类框架恰好成了合规自检的趁手工具。

说到这儿必须划一条红线：这类工具的定位，是给安全研究者、设备厂商、企业蓝队做授权测试与防御研究用的。在拿到明确书面授权之前，对任何人任何设备的未授权扫描和利用，都是违法且违背伦理的。工具本身中立，怎么用全在持工具的人。如果你只是好奇自己的路由器安不安全，在自己家里的设备上跑一跑无可厚非；但拿它去碰别人的网络，那就是另一回事了。

上手其实不麻烦。它依赖 Python 环境，装上几个网络和密码学相关的库，拉下来代码跑主程序就能进控制台。第一次用，建议你从官方文档里的示例模块起步，先拿虚拟靶机练手，熟悉了 use / set / check / run 这一套节奏，再考虑真机测试。社区里也有专门的交流频道，新手遇到问题基本都能找到答案。项目本身到现在仍在持续吸收新公开的漏洞模块，设备厂商每爆出一个新固件缺陷，社区往往很快就能补上对应的利用模块。

作为一款开源项目，它的协议边界（见文末）相当友好，对个人和企业都几乎是零门槛。
