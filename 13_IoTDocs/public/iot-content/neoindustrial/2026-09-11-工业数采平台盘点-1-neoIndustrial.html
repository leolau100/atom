工业软件这事儿，向来是"贵到离谱"和"重到跑不动"二选一。

有人嫌 Kepware 一套够买台机床，有人嫌 Ignition 装起来比造产线还慢，还有人用的东西老旧到连 AI 的影子都看不见。可数字孪生世界有个残酷真相：你 3D 模型画得再华丽，没有真实数据灌进去，也就是个精致的空壳。

这位开发者不爽了。他不爽的方式很硬核——放下了画笔，打开了 Visual Studio。

故事得从一台铝挤压机说起

这位开发者是个美术生。色彩、光影、构图才是他的母语，写代码是半路出家。但他手里的铝挤压数字孪生项目已经落地、还在疯狂迭代：三语（中英越）、带 AI 分析、温度趋势看板、挤压周期自动落库、毫米级模型位移、实时对应现场设备运转。

问题卡在数据上。数字孪生要连工厂里每一台设备——PLC、CNC、传感器、仪表、电力柜、楼宇控制器——它们说着完全不同的语言：Modbus、S7、FOCAS、BACnet、IEC 61850……市面上要么贵、要么重、要么老。没找到能用的。 于是他一个人，不到三个月，从零写出了 40 个工业协议驱动、4 种数据库并行写入、MQTT 双层毫秒推送、50 个 MCP AI 原子工具、REST API、Dashboard 监控大屏。

一句话：这不是又一个"工业软件"，是一个艺术生为数字孪生世界打造的数据基座。现在社区版 Apache 2.0 永久免费开源。

它到底是个啥？不是又一个 Modbus 调试器

先把话说清楚：NeoIndustrial 是一套生产级工业数据采集引擎，不是你本地调两下 Modbus 就关掉的小玩具。

从冲压车间的 PLC，到海上风场的 IEC 61850 变电站，从 CNC 五轴加工中心的 Fanuc 控制器，到半导体 SECS/GEM 机台——一套代码全部通吃。它干的是"采集—发布—落库"这条流水线：把设备数据捞上来，毫秒级推到 MQTT，并行写进 4 种数据库，再顺手喂给 AI。你只管把时间花在工艺优化和业务分析上，不用再纠结"谁连得上谁"。

社区版 Apache 2.0，无加密、无认证、无 License、无硬件绑定，解压即用。

40 种协议，一口气通吃

最炸裂的就是这份协议清单。别人大多单品类——只做 PLC，或者只做 CNC；NeoIndustrial 是全品类一份清单：

PLC / 控制器（11 种）：Modbus TCP / RTU、Siemens S7、Siemens 840D、Beckhoff ADS、CODESYS、Mitsubishi FX / MELSEC、Keyence KV、Panasonic Mewtocol、Omron FINS/HostLink。

CNC 数控机床（4 种）：Fanuc FOCAS、Haas、Mazak、Heidenhain。

工业以太网（3 种）：EtherNet/IP、Profinet、OPC UA。

现场总线（3 种）：PROFIBUS、DeviceNet、CC-Link。

电力 / 能源（3 种）：IEC 104、IEC 61850、DNP3。

楼宇自动化（5 种）：BACnet、KNX、DALI、LonWorks、MBus。

物联网 / 半导体 / 其他（11 种）：MQTT Subscribe、Sparkplug B、HTTP REST、DLMS/COSEM、HART IP、MTConnect、SECS/GEM、OPC DA、OPC UA PubSub，以及内置 20+ 模拟变量的 Simulator 驱动。

意思很直白：你厂里藏着什么怪设备，它大概率都能聊两句。

数据怎么流：毫秒级三层出口

架构不复杂，但很扎实。底下是 DataCollectionEngine：毫秒级轮询、字节序自适应，把各种协议的数据归一化。往上走三条腿：

MQTT 双层话题：一层是每轮周期的批量 JSON 包（设备级），一层是逐变量的子话题单值推送，还兼容 Sparkplug B。上云就是毫秒级的事。

4 种数据库并行写入：SQLite / MySQL / SQL Server / PostgreSQL，表结构统一（industrial_data(id, db_type, device, variable, data_type, value, unit, timestamp)），自动建表。

MCP / REST：AI 数据面 + HTTP 实时查询接口，Bearer Token 认证。

举个 MQTT 包的样子，一台"28 号挤压机"一轮采出来长这样：

{ "timestamp": "2026-07-16T14:30:00.123", "driver": "Simulator", "device": "28号挤压机", "values": [ {"id": "temperature", "dt": "float32", "v": 245.6, "u": "℃"}, {"id": "pressure", "dt": "float32", "v": 32.1, "u": "MPa"} ] }

最骚的操作：把 AI 直接接进车间

这才是 2026 年该有的样子。平台内置 MCP Server，50 个 AI 可调用原子工具——任何支持 MCP 的客户端（Claude Desktop 等）连上之后，你可以用自然语言直接管设备：

用户：帮我添加一台三菱 FX5U PLC，IP 192.168.1.50，采集 D100 温度、D101 压力
AI：调用 add_device → add_variables → reload_config → 设备上线

工具覆盖设备 CRUD、变量管理、采集启停、实时查询、数据库查询、数据源管理。别人还在论坛里讨论"AI+工业"是什么概念，这哥们已经让 Claude 上手帮产线加设备了。

5 分钟跑起来，连真设备都不用

上手门槛低到离谱。环境只要 Windows 7 SP1+ 和 .NET Framework 4.8，4GB 内存。两种方式：下载 Release 包双击 setup.bat+运行 exe，或者 git clone 后用 VS 打开 .sln 编译。

最贴心的是模拟器模式——内置 20+ 模拟变量（正弦波 / 方波 / 随机 / 递增），没硬件也能跑通全链路：

启动 NeoIndustrial.exe；

左侧设备树右键 → 添加设备 → 驱动选 Simulator；

点 CSV 导入 → 用模拟器默认变量 → 保存；

点 ▶ 开始采集；

看到数据滚起来了。

真设备也简单：Modbus TCP 填 IP + 端口 502 + 寄存器地址；S7-1200 填 IP + Rack=0 Slot=1 + DB 地址；Fanuc 填 IP + 端口 8193 + 宏变量号。照着配就行。

变量点：每个都能单独"洗"

平台用公司 → 车间 → 工序 → 设备四级树组织，拖拽迁移、搜索过滤都顺手。真正见功夫的是变量点（Data Point）配置——每个变量都能单独清洗、配语义、设报警：

基本信息：变量名、协议地址（如 Modbus 40001、S7 DB1.0.0）、数据类型（int16~double/string）、字节序（ABCD/DCBA/BADC/CDAB）；

线性缩放 y = kx + b，把原始值换算成工程值；修约保留 N 位小数；

报警阈值 HH / H / L / LL 四级；单位（℃、MPa、rpm、mm…）。

CSV 还能批量导入导出（UTF 8、Excel 兼容），模板文件 变量点模板_ModbusTCP.csv 桌面上现成。百台规模部署，企业版更有一键克隆，从 2 小时压到 2 分钟。

一己之力 vs 行业巨头

把 NeoIndustrial 摆到竞品堆里看，就很清楚了：

Kepware（PTC，年费 $5000+）：驱动数量勉强能比，但没有数据库写入、没有 MQTT 双层话题、没有 AI、没有 Dashboard；

Ignition（Inductive Automation，$20000+ 起步）：功能强但重如大象，Java + 数据库 + Web 服务器一套，不是给工控机用的；

组态王 / 力控 / 紫金桥：学习曲线陡，协议库老旧，无 MCP/AI，基本停在 2010 年；

Node-RED / ThingsBoard：拼凑感强，工业协议靠社区插件自生自灭，断网重连逻辑几乎为零。

Neo 不做任何人的竞品，它做的是数字孪生最缺的那块拼图——工业设备的数据基座。而且一个人、三个月、免费。

社区版 vs 企业版：两套武器系统

别用社区版的尺子量企业版——这是两套完全不同的系统。社区版帮你连上设备；企业版帮你管好整座工厂：

语义层数字孪生引擎：设备树 + 数据源树双镜像，拖拽即孪生，跨协议统一 TAG 命名空间；

Fabric 时序分析引擎：8 算子热插拔（聚合 / 相关 / 异常 / 数字孪生偏差 / 变化率 / 累积 / 阈值 / 预测），比 SQL 快 10 倍；

Dashboard 监控大屏：三级下钻、报警四色分级、多显示器投屏；

TDengine 时序库：10 万点/秒写入、10 年数据秒查；

工业级可靠性：离线缓存补发、心跳监测、指数退避重连、配置多代备份、事件规则引擎、SHA256+硬件绑定+Token 认证。

社区版该有的（40 协议、MQTT、4 库、MCP 50 工具、REST、CSV、中英双语）一样不缺，永久免费。企业版是重新设计的工厂级数据操作系统，按机台数商业授权。

One More Thing

作者在 README 里写了一段话，比任何技术参数都动人："在中国做开源的工业软件有多不容易。一个人走在深夜的车间里，只有 PLC 的指示灯在闪的时候，你需要的不是更多的门槛和收费，而是一个能用的、真诚的、不设防的工具。"

所以他把它干干净净地开源了：不用花一分钱，不用申请 License，不用看任何人脸色——下载、编译、连上你的设备，就这么简单。

如果你在厂里用它连上了 PLC、解决了实际问题，欢迎在评论区聊聊你的使用场景。一个人走得快，一群人走得远；这玩意儿一定还有 Bug，但真诚的东西，迟早会遇到真诚的人。
