# 十分钟读完一本书 · 视频生产流水线

> 剪辑/草稿/字幕/封面等剪映侧操作细节，全部见 **`capcut-draft-manager`** skill（本目录同级）。
> 本文只约定「内容怎么写、链路怎么串、交付到哪」。

## 一、铁律

1. **严格逐本串行**：一本书从核对资料 → 文稿 → 配图 → TTS → 剪映草稿 → 双封面 → 导出 → B 站发布 → 评论置顶 → 状态回填，**全链走完再做下一本**。不要提前集中备料/批量建目录/批量写元数据（用户会当成「批量处理」而打断）。
2. **持续执行不设数量上限**：逐本串行一直做下去，不要在第 20 本或任何数量主动停下；只有用户明确叫停才停。每完成一本写进度到当日日志与交接说明，队列用尽按榜单顺序继续挑经典书目。
3. **四大名著一律跳过**（尤其《红楼梦》）。
4. 改剪映 JSON 前必须完全退出剪映，同时只开一个草稿。见 capcut 技能「铁律」节。

## 二、文稿（6000-7000 字）

- **篇幅口径：6000-7000 字**，统计方式=正文含标点、不含标题与空白。落笔前先按「36 段 × 180 字」估算。
- **开头固定**（第一句就是它，不要后补）：
  > 今天想跟你聊的这本书，它叫《书名》。
- **结尾固定**：
  > 十分钟读完一本书，我们下本见。
- 内容聚焦**作品本身**：情节推进、人物关系、关键转折、金句、给普通人的启发。
  **不要**写作者生平大段、出版社信息、写作技法评价；开头之后直接进故事。
- 语言口语化，像跟朋友聊天，段落短、有转场。
- **禁止直角引号 `「」`**：会被字幕切片逻辑切成孤立句，导致 TTS 报 40402002。需要引用时用书名号或直接叙述。
- 常见残留要自查：中英混杂词（chain / KPI / daily 等）、繁体字、重复段落、字数越界。

## 三、配图（一本书一张）

- 一张主题插画即可，**封面直接复用同一张图 + 叠书名**，不二次生图。
- 风格 = **明亮高饱和写实摄影**（不是插画/水彩）：每张图体现书名核心意象，主体偏右、左侧留白、画面无文字。
- 验收阈值：HSV 的 `S ≥ 0.32` 且 `V ≥ 0.75`（脚本 `clean_ai_mark.py` 可量）。
- 生成 prompt 要写清：写实摄影 / 专业单反 / 高饱和大面积色块 / 色彩对比清晰；并明确不要：插画水彩 / 低饱和淡彩 / 深色背景 / 文字水印。
- 图片**不要输出到 `/tmp/jy_tts_stage/<书名>/`**（`make_jy_draft.py` 的 auto-heal 会清掉该目录），放 md 同目录。
- 去 AI 标识：`clean_ai_mark.py --mode clone`（亮底默认中值会抹花木纹）。

## 四、文章双封面（每本必做）

```bash
python3 "$SK" covers -s "<书名>"
```

- 输出到该书 markdown 同目录：竖版 `<书名>_封面.png`(1080×1920) + 横版 `<书名>.png`(2176×1024)。
- 底图是 `scripts/` 里的固定模板，与书籍配图无关，**不是 bug**。

## 五、视频链路（概要，完整命令见 capcut 技能「标准链路」）

```
make_jy_draft.py --drafts-root /tmp/jy_tts_stage   # TTS + 素材（SAMI 夏雨嫣）
export_jy_assets.py                                # wav/mp3/srt 到 md 同目录
jy_draft.py copy -s <书名>                          # 以模板草稿复制
inject_srt.py                                      # 注入字幕 + 配音
jy_draft.py fit-duration                           # 配图/BGM 对齐总时长
fix_spin.py <书名> --per-turn 10                   # 修正光盘旋转关键帧（必做）
jy_draft.py fix-subtitles --from <模板书>           # 字幕样式对齐
split_subtitles.py <书名>                           # 按标点切小句
apply_layout_template.py <书名>                     # 坐标模板
jy_draft.py set-bg / fix-cover / covers            # 配图、草稿封面、文章双封面
jy_draft.py reopen                                 # 重开剪映并置顶
```

- **TTS 必须设** `no_proxy` / `NO_PROXY=sami.bytedance.com,bytedance.com`，否则本机 SOCKS 代理会让 websockets 报 `requires python-socks`。
- **光盘旋转必须跑 `fix_spin.py`**（紧跟 `fit-duration`）。母版里那张唱片是一条独立 video 轨，旋转由 `segment.common_keyframes` 的 `KFTypeRotation` 驱动，终点 `time_offset` 固定是《小王子》的片长 570.3s。而 `fit_tracks` 只改 `target_timerange`/`source_timerange`，**完全不碰 `common_keyframes`** —— 结果片长拉到 1400s+ 之后，唱片转完 9.5 分钟就静止，后面 14 分钟一动不动。`fix_spin.py` 把终点 `time_offset` 对齐到片长，并按「每圈 N 秒」重算总转角（默认 10s/圈）。**漏掉这一步 = 片子后半程唱片是死的。**
  - `--per-turn` 档位：`5` 很快 / `10` 快（默认，2026-11-18 用户选定）/ `15` 很醒目 / `30` 均衡 / `60` 接近原始观感 / `0` 只修时长不同步不改转速。**脚本幂等**——重跑是按片长与每圈秒数重算总转角，不会角度叠加，可随时改档位重来。
  - 本脚本会改剪映草稿 JSON，**运行前必须先 `open_draft.py --quit-only` 完全退出剪映**，且一次只改一本书。
- 剪映**没有命令行导出**，成片只能 GUI 导出（`scripts/handoff_tools/jy_gui/export_one_book.py`）；导出前确认剪映窗口未被遮挡、无隐私屏拦截。
- 剪辑完成后**草稿要上传到剪映个人云空间**做归档（GUI 操作：草稿项的云备份/上传入口）。这一步目前无法脚本化，属人工或半自动步骤，做完在 `交接说明.md` 进度表标注。

## 六、发布与回填

- B 站账号「小艳儿咩」，标题 `《书名》- 金句`，分区「知识」，标签 `十分钟读完一本书/读书/书名/作者/主题`，封面用横版 `<书名>.png`。
- 发布成功后**必须发简介评论并置顶**（内容 = 简介原文）。
- 腾讯文档书单 `https://docs.qq.com/sheet/DTGJsZmFLRFpuWGVS`：18 个榜单子表，命中书名的所有行在 **col14** 写 `✅YYYY-MM-DD 已发布 <BV号>`，写完回读校验。
- 具体接口与踩坑见 `交接说明.md` 第 5、6 节。
